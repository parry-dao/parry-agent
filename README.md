# PARRY Agent

Welcome to the official PARRY Agent repository! This project is based on an early artificial intelligence program developed by American psychologist and computer scientist Kenneth Colby in 1972. PARRY was designed to simulate the thought processes of patients with paranoid schizophrenia, making it a fascinating early exploration of AI's potential to mimic human psychological states, especially those involving mental illness.

## Project Overview

PARRY was originally created to investigate AI's ability to simulate human psychological conditions, with a particular focus on understanding and modeling the symptoms of paranoid schizophrenia. The core of this project is an experiment in how AI can simulate mental states through natural language processing.

### Key Features of PARRY:

1. **Objective**: PARRY serves as a research tool to explore psychology and human-computer interaction. It specifically focuses on simulating the paranoid thought patterns often seen in schizophrenic individuals.
2. **Technology Principles**:
   - PARRY uses simple rule-based logic and models to simulate paranoid reasoning. For example, it is sensitive to threatening words and responds with paranoid interpretations.
   - This is an early example of **rule-based natural language processing (NLP)**, which was far simpler compared to today's machine learning or neural networks.
3. **Conversation Style**:
   - PARRY’s dialogue is marked by an intense sensitivity to perceived threats and hostility. It tends to interpret common interactions in a paranoid manner, making it appear as if people are attacking it.
4. **Comparison with ELIZA**:
   - **ELIZA** (1966) was an earlier program that mimicked a psychotherapist, primarily using simple questions and repetitive patterns to engage with users.
   - PARRY, however, was more complex. It incorporated emotional states and belief systems, making it seem more like a person with distinct psychological characteristics.
5. **Applications and Historical Significance**:
   - In a famous 1970s experiment, researchers allowed PARRY and ELIZA to "converse," simulating a psychotherapy session. This interaction remains a landmark example of early AI dialogue systems.
   - PARRY represents an important milestone in AI history, illustrating how computing could be used to simulate complex psychological states, such as paranoia.

## How PARRY Works

PARRY is designed to respond to user input in a way that mirrors paranoid reasoning. It is highly sensitive to any perceived threat and will generate responses that reflect a distorted view of reality. The program's ability to simulate a mental state such as paranoia makes it a unique and historically significant AI project.
